# 六十の風景 — 自動鑑定アプリ 仕様書 v0.2

作成日 2026-10-10（v0.2 同日更新：六十の風景の執筆完了・自前の名への付け替えを反映）。Claude Codeへの最初の指示として使う。学理・文体・申込フォーム・六十の風景は同じフォルダの別ファイルを参照。

## 1. 商品

生年月日と「問い」から、算命学の宿命を一冊の鑑定書にして返す。目的は羅針盤として読まれた先で本人がエンパワーメントされること。苦労を「輝くための段取りだった」と読み替え、同時に「これからどう生きるかは自分が決める」を必ず対で渡す。

| 段階 | 価格 | 内容 | 生成 |
|---|---|---|---|
| 無料 | 0円 | 生年月日入力 → 日干支の風景（一段落）＋構造の一言 | 自動 |
| 完全版 | 3,980円 | 5問の申込回答を入れて、問いに答える鑑定書（PDF） | 自動 |
| 監修版 | 9,800円 | 完全版を逆井が一読・加筆・承認して送付 | 自動＋人 |
| 対話版 | 30,000円 | 鑑定書＋60分の対話 | 人 |

最初のリリースでは完全版も全件「承認後に送付」とする（監修版と同じフロー）。承認率が安定したら完全版を無人化する。

## 2. 導線

SNS（60枚の風景カード）→ LP → 無料診断（生年月日のみ）→ 問いを書く（5問）→ 決済 → 算出 → 生成 → PDF → 承認 → メール送付 → LINE公式で受け皿

## 3. アーキテクチャ（二層分離）

### 3.1 算出層（決定的・LLM不使用）

入力：生年月日・性別。出力：宿命表JSON。

算出する項目：
- 年干支・月干支・日干支（立春起点、節入日で月を切替、日は1日干支番号＋誕生日−1）
- 蔵干（二十八元表：誕生日−節入日の日数で初元・中元・本元を決める）
- 陽占：十大主星5つ（日干×天干・蔵干）、十二大従星3つ（日干×地支）
- 天中殺（日干支の番号から6グループ）、宿命天中殺の判定（生年・生月・二天中殺・日座）
- 位相法：宿命内（日支・月支・年支の組合せ）、特殊変化（律音・納音・大半会・天剋地冲・大三合会局・方三位）
- 大運：起運年齢（1〜10歳）、10年ごとの干支・主星・従星、各柱との位相、大運天中殺
- 年運：各年の干支・主星・従星、各柱との位相、年運天中殺（生年〜120年分）
- 数理法：十干別エネルギー、五行別、総合計、排気口（従星3つの平均）
- 八門法：日干中心の五方向配置、型（青龍・白虎・朱雀・玄武・騰蛇）、順型・逆型
- 宇宙盤：三干支の番号、行動領域の形（三角・直線・点）
- 六十花甲子：日干支・月干支・年干支それぞれの番号（甲子＝1 … 癸亥＝60）・季節・従星・風景の名。名と従星は45_六十花甲子_照合表.mdから引く。風景の本文は30〜39_風景_*.mdから番号で引く

算出の手順・早見表・配置規則・テストケースは 60_算出手順.md に全部ある（二十八元表、十大主星・十二大従星の早見表、陰占→陽占の位置対応、天中殺の番号判定、日干支の基準日計算）。節入日は年ごとの二十四節気が必要。計算（天文計算ライブラリ）か、年表データの持ち込みか、どちらかを選ぶ。精度はアプリ出力との一致で担保。

**テストケース（必須）：1973-11-23 男性**
- 陰占：日 癸亥(60) 月 癸亥(60) 年 癸丑(50)。蔵干本元：日 壬、月 壬、年 己
- 陽占：北 貫索星、西 石門星、中央 石門星、東 車騎星、南 貫索星。初年期 天南星、中年期 天将星、晩年期 天将星
- 天中殺：子丑。生年天中殺に該当
- 宿命内位相：日−月 律音（＋自刑）
- 大運：5歳起運。壬戌(5)→辛酉(15)→庚申(25)→己未(35)→戊午(45)→丁巳(55)→丙辰(65)→乙卯(75)→甲寅(85)→癸丑(95)→壬子(105)→辛亥(115)。大運天中殺は癸丑・壬子
- 数理法：甲56 己11 辛20 壬60 癸136 合計283。木56 火0 土11 金20 水196。排気口 (10+12+12)/3=11.3
- 八門法：騰蛇型（中央・水196最大）。順型（北中南272＞東中西207）
- 宇宙盤：直線（60・60・50）
- 年運 2026 丙午 司禄星・天馳星、年柱に南方害。2027 丁未 禄存星・天庫星、日月に半会×2、年柱に天剋地冲＋庫気刑。2028 戊申 牽牛星・天極星、日月に西方害×2

このケースの全項目が一致してから生成層に進む。追加のテストケースは逆井が鑑定アプリの出力PDFで供給する。

### 3.2 生成層（Claude API）

入力：宿命表JSON＋申込回答（5問＋任意1問）＋氏名（任意）。出力：鑑定書Markdown。

システムプロンプトに含めるもの：
1. 学理リファレンス（40_学理リファレンス.md）
2. 文体ガイド（10_文体ガイド.md）
3. 鑑定書の構成（下記）
4. 禁則（下記）
5. 手本：鑑定書サンプル（50_鑑定書サンプル.md）と六十の風景（29_風景_書き方の約束.md、30〜39_風景_甲〜癸.md）

鑑定書の構成（固定）：
0. はじめに — 申込の問いを「 」で引用し、先に結論を一文で言い切る
1. 日干支の風景 — 番号・干支・自前の名と、事前執筆した風景から入る。本人の問いの言葉と宿命の言葉の一致を示す。律音・月干支・年干支の風景も
2. あなたという構造 — 七つの角度（陰占・宇宙盤・数理・八門・陽占・従星・天中殺）を表で並べ「全部が同じ一点を指す」と言い切る。持っている力と空白
3. 本人が書いたパターンの正体 — 申込4問目の言葉を分解し、一句ずつ宿命表の箇所に対応づける
4. 時間軸 — 申込3問目の転機の年を大運の切替と照合。過去の大運を遡り、仮説形式（時期×領域×現象の型＋読み替え）で書く。これからの10年と年運表
5. 問いへの答え — 陽転条件を本人の言葉と並べる。怖れの正体を名指しする
6. 処方箋 — 今週2・一ヶ月2・半年2。小さな行動、各項に宿命上の理由
7. 羅針盤の一枚 — 表。締めの一文
8. 用語の言い換え表

風景は六十花甲子ごとに事前執筆した60本（30〜39_風景_*.md）を差し込む（生成しない）。見出しは「漢数字の番号　干支　自前の名」（例：六十　癸亥　源へ帰る水）。各風景末尾の斜体「出典の言葉」と、各冊の斜体「制作メモ」「書き方の約束」は制作用で、鑑定書・カード・PDF・無料診断には載せない。

禁則：
- 教材・流派・出典・「〜と書かれています」の類に一切触れない。言い切る
- 六十花甲子の教材由来の呼び名（例：溝渠の水、禄馬同郷、崑崙還元の水）を出さない。風景の名は30〜39の自前の名のみ。教材由来の呼び名は45_六十花甲子_照合表.md（算出層専用）にだけ置き、生成層のプロンプトにも出力にも入れない
- 決定論にしない。「苦労は段取りだった」と「これからは自分が決める」を必ず対で書く
- 病気・死・寿命を断定しない。害は「体にサインが出やすい時期」として部位を添えるまで
- 家族（配偶者・子・親）の人格を断定しない。本人との関係の読みに留める
- 「〜ではなく〜」「つまり」「だからこそ」は一通に各一回まで。三つ並べる列挙を多用しない。段落を格言で閉じない

生成後の自動チェック：禁則語（教材、流派、出典、算命学の教科書、〜と書かれています）の検出。教材由来の六十花甲子の呼び名（45_六十花甲子_照合表.mdの列から生成）の検出。構成見出しの欠落検出。文字数（完全版は6,000〜9,000字目安）。

### 3.3 PDF

水墨のトーン。墨色、薄い藍、和紙の白い余白。写真は使わない。風景は一枚の墨絵か文字だけ。本文は縦書きでなく横書き、明朝。表紙に番号・日干支・自前の名と風景の一行。巻末に用語の言い換え表。

### 3.4 周辺

決済：Stripe（Checkout）。送付：メール（PDF添付＋LINE公式への導線）。承認：管理画面で生成結果を表示し、加筆・承認・再生成ができる。データ：申込・宿命表JSON・生成結果・承認履歴を保存。再生成はJSONから何度でも可能。

## 4. 無料診断

入力：生年月日（性別は任意）。出力：番号・日干支・自前の名、季節、風景の一段落、構造の一言（一文）。CTA：「問いを書いて、続きを読む」。SNS共有用に風景カード画像を出す（番号・干支・名・結びの一行）。

## 5. 申込フォーム

20_申込フォーム.md のとおり。5問＋任意1問、全て自由記述。生年月日・性別・氏名（任意）・メール。

## 6. 開発順序

1. 算出層＋テストケース一致
2. 生成層（システムプロンプト組み立て、サンプル生成、禁則チェック）
3. 無料診断ページ
4. 申込→決済→生成→承認→送付
5. PDF体裁
6. 60枚の風景の差し込み（執筆済み：30〜39_風景_*.md）

## 7. 未決事項

- 商標・ドメイン・各SNSハンドルの確認（「六十の風景」）
- 出生時刻は使わない（算命学は不要）。性別は天中殺の子への影響など一部で使うため任意で取る
- 教材の追加予定あり。学理リファレンスは差し替え前提で、生成層は参照ファイルを読む設計にする

## 8. 技術的な決定（v0.2で確定）

- 言語・構成：Python 3.12。算出層は依存なしの純Pythonパッケージ（`sanmei/`）＋pytest。Web層はFastAPI＋Jinja2（サーバー描画、JSは最小）。生成層はAnthropic SDK。PDFはWeasyPrint（HTML/CSS→PDF、フォントはNoto Serif JP）。DBはSQLite（単一ファイル）から始め、必要になったらPostgresへ
- ホスティング：Railway（Dockerfile一つでWeasyPrintごと動く）。ドメインは「六十の風景」の確認後に当てる。それまではRailwayの既定URL
- 周辺サービスはすべてアダプタ越し・環境変数で差し替え：決済 Stripe Checkout（最初はテストキー）、メール Resend、LINE公式は固定リンクのみ。鍵が無いときはダミーアダプタ（コンソール出力）で全導線が通る
- 節入日：`scripts/gen_setsu.py` で1900〜2100年の12節の日付（JST）を天文計算し、`sanmei/data/setsu.json` として生成・コミットする。生成後、干支暦の早見表（画像）と任意の数年分を逆井が目視で突合してから採用。**教材の画像・PDFはリポジトリに入れない**（照合は手元で行い、結果のJSONだけを置く）
- リポジトリは非公開。風景60本・文体ガイド・学理・照合表はリポジトリ内 `content/` に置く（プロジェクト「鑑定」の 六十の風景/ をそのままコピー）
- 開発順序1の完了条件：60_算出手順.md のテストケース6件がpytestで全項目一致し、節入日JSONが突合済みであること
