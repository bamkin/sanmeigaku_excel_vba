# 申込フォーム — 六十の風景

全て自由記述。選択式は使わない。回答10分以内。質問文は鑑定書と同じ文体。

## 基本情報

- お名前（任意。鑑定書の宛名に使います）
- 生年月日
- 性別（任意）
- メールアドレス

## 問い（5問＋任意1問）

1. 今、一番気になっていることを一つ、そのままの言葉で書いてください。仕事でも家族でも体でも、整理されていなくて構いません。
2. それについて、あなたの中では「本当はこうしたい」という方向がありますか。あるなら書いてください。なければ「ない」で結構です。
3. これまでの人生で「あの時期が転機だった」と思う年を一つか二つ。年齢か西暦と、何があったかを一行で。
4. 人生で繰り返し起きている気がすること、または「自分はいつもこうなる」と感じるパターンがあれば書いてください。
5. この鑑定を読み終えたとき、どうなっていたら「受けてよかった」と思いますか。

任意：今の体調や、体で気になっていることがあれば。

## 各問いの用途（内部）

| 問い | 鑑定書での使い方 |
|---|---|
| 1 | 鑑定の収束点。冒頭で「 」引用し、第五章で答える |
| 2 | 処方箋の書き方を決める。方向があれば宿命と合う／合わないを言い切る。なければ宿命から方向を立てる |
| 3 | 大運・年運照合の芯。大運の切替年と一致すれば第四章の核になる |
| 4 | 一句ずつ宿命表の箇所（主星・従星・分離条件・数理の空白）に対応づけ、構造的必然として返す |
| 5 | 着地点：安心／決断の後押し／意味づけ。言い切る方向を決める |
| 任意 | 害の部位（北方＝腎・耳、南方＝心・小腸、東方＝肝・目、中央＝脾・胃、西方＝肺・大腸・鼻、天頂＝自律神経）と照合 |

## 訊かないこと

- 「人生のテーマは何だと思いますか」—答えられる人は少なく、答えられる人は鑑定が要らない。テーマは鑑定側が宿命から立てて問いと結びつける
- 「何を感じているか」単独—抽象的すぎる。1に吸収
- 出生時刻—算命学では不要

## 鑑定書冒頭の型

「あなたは申込のとき、こう書かれました。『……』。この一文から始めます。」
