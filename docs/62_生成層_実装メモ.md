# 生成層 実装メモ（開発順序2）

`seisei/` の実装で決めたこと、確認待ちの項目。

## 構成

| ファイル | 内容 |
|---|---|
| seisei/landscape.py | docs/30〜39 を読み、番号→風景（見出し・本文）。「出典の言葉」「制作メモ」「書き方の約束」は除く |
| seisei/prompt.py | システムプロンプト（役割・文体ガイド・書き方の約束・学理・構成と禁則・出力形式・手本・六十の風景）と依頼メッセージ（宛名・宿命表・申込回答・差し込む風景）。風景の差し込み |
| seisei/checker.py | 禁則語・教材呼び名（docs/45 から生成）・見出し・文字数・頻度制限・感嘆符絵文字 |
| seisei/generate.py | Claude API 呼び出し、後処理（差し込み→チェック） |
| seisei/__main__.py | CLI（生成／乾走り／既存ファイルのチェック／生出力の後処理） |
| samples/ | 申込回答JSON、乾走りのプロンプト、生成サンプル、docs/50 との比較 |

```
export ANTHROPIC_API_KEY=...
python -m seisei --birth 1973-11-23 --sex male --answers samples/1973-11-23_申込回答.json --name "逆井 勤" --out out/逆井.md
python -m seisei ... --dry-run                      # API を呼ばずプロンプトを書き出す
python -m seisei --check docs/50_鑑定書サンプル.md    # 禁則チェックだけ
python -m seisei --birth ... --postprocess raw.md --out out.md   # 生出力に差し込みとチェック
```

## API の設定

- モデル：`claude-opus-5-5`（環境変数 `SEISEI_MODEL` で差し替え）。思考は adaptive（既定）、`output_config.effort` は `high`（`SEISEI_EFFORT`）
- ストリーミングで受けて `get_final_message()`。`max_tokens` 32,000
- システムプロンプトに `cache_control`（固定部分なので2回目以降はキャッシュ読み）。依頼メッセージは毎回変わる
- サーバー側フォールバック（安全分類器が拒否したとき代替モデルで続行）を既定で有効。`SEISEI_FALLBACK=0` で無効
- `stop_reason` が `refusal` ならエラー、`max_tokens` なら切れたことをエラーに出す
- 実機での生成は API キーを入れてから（手順は README「実機でサンプルを生成して比較を更新する」）

## 風景の差し込み

モデルは第一章の見出し直後に `[[風景:日]]` の一行だけを置く。後処理が本文に置き換える。印が無ければ第一章の見出し直後に差し込み、note を出す。`[[風景:月]]` `[[風景:年]]` も使える。差し込んだ本文は禁則チェックの対象から外す（文字数には含める）。

## 確認待ち

1. **教材の呼び名と普通名詞の衝突（決定済み）**。docs/45 に「禁則」列が入り、普通名詞・慣用句になっている7語（香木・常緑の木・果実の木・沈む石・盆栽の花・風前の灯火・芸術家の星）は警告、残り53語はエラー。チェッカーはこの列を読む。警告は不合格にせず承認画面に表示する。差し込んだ風景本文はチェック対象外。
2. **docs/00 の禁則に例として挙がる呼び名**（溝渠の水・禄馬同郷・崑崙還元の水）は、プロンプト組み立て時に取り除いている。
3. **文字数**。風景の差し込み分（約450字）を含めて 6,000〜9,000 字で見ている。
4. **依頼メッセージの年運**は今年の前年から12年分。それより先は宿命表JSONにあるが渡していない。
