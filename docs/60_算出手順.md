# 算出手順 — 算出層の実装仕様（干支暦ver4.0・干支算出資料より）

算出層（決定的・LLM不使用）が従う手順と表。出典は教材の干支暦ver4.0と「干支算出」資料。すべて照合済み（本文末のテストケース）。出力・鑑定書・プロンプトには教材名を出さない。

## 0. 定義
- 六十干支番号：甲子＝1 … 癸亥＝60。番号n → 天干＝十干[(n−1) mod 10]、地支＝十二支[(n−1) mod 12]
- 十干：甲乙丙丁戊己庚辛壬癸（陽陰陽陰…）。五行：甲乙木 丙丁火 戊己土 庚辛金 壬癸水
- 十二支：子丑寅卯辰巳午未申酉戌亥。月：寅2 卯3 辰4 巳5 午6 未7 申8 酉9 戌10 亥11 子12 丑1
- 日付はJST（暦の日単位）。出生時刻は使わない

## 1. 節入日
- 干支年は2月の節入日（立春）から。干支月は各月の節入日から
- 節（12）：立春(2月)・啓蟄(3月)・清明(4月)・立夏(5月)・芒種(6月)・小暑(7月)・立秋(8月)・白露(9月)・寒露(10月)・立冬(11月)・大雪(12月)・小寒(1月)
- 求め方：太陽黄経が 315°,345°,15°,45°,75°,105°,135°,165°,195°,225°,255°,285° に達する瞬間（JST）の「日」。天文計算ライブラリで年ごとに算出し、干支暦の節入日表と突合してから採用する（干支暦の早見表は画像のため、突合はサンプル年を目視）
- **節入日当日に生まれた人は当月扱い**（二十八元は初元）。節入日の前日までは前月扱い

## 2. 年干支・月干支・日干支
- 年：生年の立春以後なら生年、立春前（1月1日〜立春前日）なら前年。番号 ＝ (西暦−4) mod 60 ＋ 1（1973→50 癸丑）
- 月：生日が当月節入日以後なら当月、前なら前月。前月が1月なら年も前年に戻す。月干は年干から五虎遁：年干 甲己→寅月は丙寅、乙庚→戊寅、丙辛→庚寅、丁壬→壬寅、戊癸→甲寅。以後、卯月・辰月…と干支を1ずつ進める
- 日：**年月の切替に関係なく暦日そのもの**で決める。番号 ＝ (基準番号−1 ＋ 基準日からの経過日数) mod 60 ＋ 1。基準：1930-06-01＝壬午(19)。61以上は60を引く

## 3. 二十八元（蔵干）
d ＝ 生日 − 当月の節入日（当月扱いの場合。0＝節入日当日）。前月扱いの場合は本元固定。
初元は 0 ≤ d ≤ n1、中元は n1 < d ≤ n1+n2、本元は d > n1+n2。20日目以降はどの支でも本元。

## 4. 陰占の配置
```
      日    月    年
天干  日干  月干  年干        （心）
地支  日支  月支  年支        （現実）
蔵干  日支の元 月支の元 年支の元
```
方向：日＝西（配偶者・家庭・過去）、月＝中央（自分・立場・現在）、年＝東（仕事・未来・友人）。

## 6. 天中殺
番号で決まる：1〜10 戌亥、11〜20 申酉、21〜30 午未、31〜40 辰巳、41〜50 寅卯、51〜60 子丑。
- 本人の天中殺＝日干支の番号から
- 宿命天中殺の判定：年支が本人の天中殺に含まれる→生年天中殺。月支→生月天中殺。両方→二天中殺。日支→生日天中殺（日支が自分の天中殺に入るのは甲戌・乙亥のみ＝日座天中殺）。年と日→互換
- 年運の天中殺：その年の年干支の地支が本人の天中殺グループに入る年（12年に2年連続）。大運の天中殺：大運干支の地支が入る旬（20年）

## 7. 大運
- 順逆：年干が陽で男、または年干が陰で女→順行。年干が陰で男、または年干が陽で女→逆行（照合済み：1974-01-15 年干癸・女→順行 丙寅から、同日・男→逆行 甲子から）
- 起運年齢：順行は生日から次の節入日まで、逆行は生日から前の節入日までの日数 ÷ 3、**四捨五入**（照合済み：1974-01-10 女 25日→8.33→8歳、男 4日→1.33→1歳、1974-01-15 女 20日→6.67→7歳、1962-03-10 女 4日→1歳、1951-02-03 女 28日→9.33→9歳。切り上げ・切り捨てはいずれかの例で外れる）
- 順行は月干支の次の干支から10年ごと、逆行は前の干支から10年ごと。大運の年＝生年＋起運年齢（1974生・7歳→1981）
- 大運干支の地支が本人の天中殺に入る旬に「＞」（大運天中殺。1974-01-15 男：初旬 甲子に＞）
- 各大運に対し：天干→十大主星（日干から）、地支→十二大従星、各柱の地支との位相、天中殺判定
- 年運：その年の干支（甲子1〜）。同じく主星・従星・位相・天中殺

## 8. 位相・数理・八門・宇宙盤
40_学理リファレンス.md の「位相法」「宇宙盤・数理法・八門法」の定義で算出する。
- 数理法（照合済み）：材料は天干3つ＋**全蔵干（初元・中元・本元をすべて、支ごとに1〜3個）**。十干ごとに、その干と地支3つ（日支・月支・年支）それぞれの従星点数の合計を出し、出現回数を掛ける。例 1974-01-15（丙辰 乙丑 癸丑、蔵干 辰＝乙癸戊、丑＝癸辛己×2）：乙は辰10＋丑8＋丑8＝26、出現2回→52。癸は辰6＋丑10＋丑10＝26、出現4回（年干＋辰＋丑＋丑）→104。合計270。1973-11-23は癸136 甲56 壬60 辛20 己11＝283
- 八門法：日干の五行を中央、日干を生じる五行を北、日干が生じる五行を南、日干が剋す五行を東、日干を剋す五行を西に置き、数理法の五行別合計を入れる（丙：中央火22、北木52、南土58、東金34、西水104）
- 宿命表の蔵干欄には初元・中元・本元を全部書く（上から初元・中元・本元）。陽占に使うのは d で決まった一つの元で、宿命表ではその元の左に「＞」を付ける（前月扱いなら本元の行に3つ）。地支の行の「＞」は宿命天中殺の柱
- 位相法は日−月、月−年、日−年の3組。宿命天中殺は該当する柱に「＞」を付ける（1974-01-15は月・年とも丑→二天中殺）
