# 六十の風景 — 書き方の約束

- 使う材料は、各干支の名、季節と月、自然の解釈、三つの特徴、従星。これ以外の性質を風景から生やさない
- 風景は見えるものだけで書く。評価の語（聡明、孤独、純粋）は風景の中に入れず、風景が終わってから一行で言う
- 一文に一つの像。短い行を重ね、長い一文を一本だけ挟む
- 比喩は水だけ。工学の語は構造の章で使い、風景の章には入れない
- 本文では教材・流派・出典に一切触れない。言い切る。対応関係は末尾の「出典の言葉」に制作用として残すが、商品には載せない
- 最後の一行は格言にしない。言い切って終わる。余韻は残してよいが、初見の他人が読んで意味が取れない場合だけ個別に直す
- 見出しは「漢数字の番号　干支　名」。番号は六十花甲子の順（甲子＝一 … 癸亥＝六十）
- 風景の名は自前のもの（本文の像から起こした名）。教材・流派由来の呼び名は見出しにも本文にも使わない
