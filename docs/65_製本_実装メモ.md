# 製本 実装メモ（開発順序5）

鑑定書 Markdown → PDF。`seihon/` に実装。WeasyPrint（HTML/CSS → PDF）、Noto Serif JP、A4 横書き。

```
python scripts/get_fonts.py                      # Noto Serif JP を fonts/ に取得（一度だけ。リポジトリには入れない）
python -m seihon samples/1973-11-23_実機2.md --birth 1973-11-23 --sex male --name "逆井 勤" --today 2026-10-14 \
  --out samples/1973-11-23_実機2.pdf --html out.html
```

| ファイル | 内容 |
|---|---|
| seihon/render.py | `cover_meta`（表紙の情報）、`report_html`（Markdown → HTML、章ごとに section）、`report_pdf`（WeasyPrint） |
| seihon/__main__.py | CLI |
| scripts/get_fonts.py | Google Fonts から Noto Serif JP（400/500/700、分割なしの TTF 3 ファイル、約 24MB）を fonts/ に落とす |
| tests/test_seihon.py | 表紙の情報、HTML の組み立て、実機2 を PDF にしてページ数とフォント（Noto Serif JP）を確認 |

## 体裁（docs/00 §3.3）

- 色は墨（#1f1f1f）・薄い藍（#3b5b7a、罫線は #9fb3c8）・和紙（表紙 #f7f4ec、本文は白）。写真・図版なし。風景は文字だけ
- **表紙**：「六十の風景／鑑定書」、番号と干支（六十　癸亥）、自前の名（源へ帰る水、32pt）、風景の一行（本文の結び「どこへ流れても、源へ帰る水です。」）、宛名、日付。ページ番号なし
- **本文**：A4、余白 上24・左右22・下26mm、10.5pt、行送り 1.95。章（## 見出し）ごとに改ページ。右上に「六十の風景」、下中央にページ番号。引用（申込の言葉）は藍の左罫、表は薄い罫線、行の途中で改ページしない
- **巻末**：第八章の言い換え表がそのまま最後の章になる。末尾に奥付の一行（鑑定書名・日付）
- 1973-11-23 の実機2（9,451字）で 17 ページ、約 230KB、生成に約 4 秒

## フォント

- `fonts/noto-serif-jp.css`（@font-face、相対 URL）と `fonts/NotoSerifJP-{400,500,700}.ttf` を `scripts/get_fonts.py` で取得。`.gitignore` で除外
- **ブラウザ向けの分割 woff2（unicode-range 付き 372 ファイル）は使わない。** WeasyPrint が埋め込むとグリフの対応が崩れて別の字で印字された（「源へ帰る水」が「源衛弾 羽」）。古いクライアントを名乗って Google Fonts から分割なしの TTF を受け取る
- WeasyPrint は `CSS()` を単独で作ると @font-face を無視する。`FontConfiguration` を HTML と CSS で共有している（`report_pdf`）
- fonts/ が無いときは Noto Serif CJK JP → IPAexMincho → IPAMincho → serif の順で落ちる。Docker では `fonts-noto-cjk` を入れているので、取得に失敗しても明朝で出る
- Railway の Dockerfile は `python scripts/get_fonts.py` をビルド時に走らせる
