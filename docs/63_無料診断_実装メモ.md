# 無料診断 実装メモ（開発順序3）

入力は生年月日（性別は任意）。出力は番号・日干支・自前の名、季節、風景の一段落、構造の一言、CTA、SNS共有用の風景カード。LLM は使わない。

## 構成

| ファイル | 内容 |
|---|---|
| shindan/service.py | 生年月日 → 算出層 → 日干支の風景（docs/30〜39）から季節の行・最初の段落・結びの一行を取り出す |
| shindan/hitokoto.py | 構造の一言。数理法で最大の五行 × 八門法の型 ＝ 25通りの定型文 |
| shindan/card.py | 風景カード（SVG 1200×630、OGP サイズ）。番号・干支・名・結びの一行 |
| shindan/app.py, templates/ | FastAPI＋Jinja2。`/`（入力）、`/shindan?birth=`（結果）、`/card/{番号}.svg`、`/apply`（開発順序4の置き場。いまは案内だけ） |
| scripts/dump_shindan.py | 60本の一段落・結びと、25通りの一言を samples/ に書き出す（目視確認用） |

```
uvicorn shindan.app:app --reload     # http://127.0.0.1:8000/
python scripts/dump_shindan.py       # samples/無料診断_風景一覧.md, samples/構造の一言_一覧.md
```

## 決めたこと

- **風景の一段落**＝各風景の本文で、季節の行（例「初冬、十一月。」）の次の段落。**結びの一行**＝本文の最後の段落。どちらも docs/30〜39 から取り出すだけで、生成しない
- **構造の一言**は一文。「あなたの中でいちばん多いのは{力}で、{器}。」。力は最大の五行から（木＝自分の場所を守る力、火＝伝える力、土＝人とものを引き寄せる力、金＝動いて切り開く力、水＝学んで溜める力）。器は八門法の型から（青龍・白虎・朱雀・玄武・騰蛇）。五行が同点のときは木火土金水の順で先のもの
- 性別は任意。入っていれば算出層に渡すが、無料診断の出力には使わない（大運は出さない）
- 生年月日の範囲は節入日データの 1900〜2100 年。外れたら入力画面にエラーを出す
- 見た目は仕様書 3.3 に合わせて墨色・薄い藍・和紙の白、明朝（Noto Serif JP を Google Fonts から。無ければ端末の明朝）。写真は使わない
- カードは SVG。PNG が要る SNS 向けには、PDF 体裁（開発順序5）でフォントを入れるときに同じ描画で PNG を出す

## 確認待ち

1. 構造の一言の25通りの文面（samples/構造の一言_一覧.md）。言葉を変えるなら shindan/hitokoto.py の二つの表だけ
2. 入力画面と結果画面の文言（templates/index.html, result.html）。LP の文面が決まったら差し替える
3. カードの文字組み（横書き・一行）。結びの一行が長い風景（例：二十四 丁亥「風の前で、灯は消えない。」は短いが、長いものは36pxで収まるか）は実機の表示で確認する
