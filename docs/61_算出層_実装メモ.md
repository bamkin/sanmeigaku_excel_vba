## 節入日

太陽の視黄経（地心・当日の分点）が 315°, 345°, … に達する瞬間を ephem で求め、JST の暦日にした。既知の値との照合：2023 立春 2/4 11:42、2024 立春 2/4 17:27、2025 立春 2/3 23:10、1951 立春 2/5 00:13（教材どおり5日）、1974 小寒 1/6 02:20、1973 立冬 11/7 22:28。

**要確認**：干支暦の早見表と任意の数年ぶんを目視で突合してから採用する（README の指示4）。節入の瞬間が深夜に近い年は暦日がずれうる。`python scripts/gen_setsu.py --year 1974` で1年ぶんの時刻を表示できる。

## 教材の記述との食い違い（2026-10-14 逆井確認済み・すべて実装側が正しい）

1. **七殺の範囲**。同じ陰陽で剋し合う天干10対（甲↔庚 乙↔辛 丙↔壬 丁↔癸 戊↔甲 己↔乙 庚↔丙 辛↔丁 壬↔戊 癸↔己）。docs/40・docs/60 を訂正済み。
2. **1951-02-03 女 の陽占**。アプリ出力は 南 司禄・西 禄存。規則どおり。docs/60 を訂正済み。
3. **1974-01-15 の年運 2027 丁未**。アプリ出力は 日 空欄、月 冲＋庫気刑、年 天剋地冲＋庫気刑。規則どおり。docs/60 を訂正済み。
4. **1962-03-10 の宿命天中殺**。年支寅・月支卯で二天中殺。アプリは宿命表に印を出していないだけ。宿命天中殺は宿命表に印を出さず JSON の項目として持つ（docs/60 §8）。
5. **大三合会局**。三合会局＋三つの天干が同じ、で確定。
6. **起運年齢が 0 になる場合**（節入日当日生まれの逆行など）。起運年齢は 1〜10 なので 1 歳とした（未照合）。

## 刑の扱い

冲と刑は重なって成立する（丑未＝冲＋庫気刑、寅申＝冲＋生貴刑）。自刑（辰午酉亥の同支）は比和・律音と重ねて出す。出力では刑を 無礼刑（子卯）・生貴刑（寅巳申）・庫気刑（丑未戌）・自刑 の名で返す。

## 性別が無いとき

大運は順逆が性別で決まるので、性別未入力のときは `taiun` に `male` / `female` の両方を入れて返す。無料診断（生年月日のみ）では大運を使わない想定。
