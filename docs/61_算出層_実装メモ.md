# 算出層 実装メモ（開発順序1）

`sanmei/` の実装で決めたこと、教材の記述と食い違った点、逆井の確認待ちの項目。

## 構成

| ファイル | 内容 |

| sanmei/setsu.py | 節入日JSONの読み込み、前後の節入日検索 |
| sanmei/pillars.py | 年・月・日干支、蔵干（d による元の選択） |
| sanmei/stars.py | 十大主星・十二大従星（早見表は規則から導出、tests/test_tables.py で表と総当たり照合） |
| sanmei/tenchusatsu.py | 天中殺グループ・宿命天中殺 |
| sanmei/iso.py | 位相法（二柱の条件、三柱の三合会局・方三位） |
| sanmei/unki.py | 大運・年運 |
| sanmei/suri.py | 数理法・八門法・宇宙盤 |

| sanmei/render.py | 確認用のテキスト表示 |

実行：`python -m sanmei 1973-11-23 male`（`--json` で宿命表JSON）。テスト：`python -m pytest`。

## 節入日

太陽の視黄経（地心・当日の分点）が 315°, 345°, … に達する瞬間を ephem で求め、JST の暦日にした。既知の値との照合：2023 立春 2/4 11:42、2024 立春 2/4 17:27、2025 立春 2/3 23:10、1951 立春 2/5 00:13（教材どおり5日）、1974 小寒 1/6 02:20、1973 立冬 11/7 22:28。

**要確認**：干支暦の早見表と任意の数年ぶんを目視で突合してから採用する（README の指示4）。節入の瞬間が深夜に近い年は暦日がずれうる。`python scripts/gen_setsu.py --year 1974` で1年ぶんの時刻を表示できる。

## 教材の記述と異なる点（要確認）

1. **七殺の範囲**。docs/40 は 甲戊・乙己・丙庚・丁辛・壬丙・癸丁 の6対を挙げるが、鑑定書サンプルは 35〜44歳の大運 己未 と年柱 癸丑 を天剋地冲としている（己↔癸）。そこで七殺を「同じ陰陽で剋し合う天干」10対（甲戊 戊壬 壬丙 丙庚 庚甲／乙己 己癸 癸丁 丁辛 辛乙）として実装した。
2. **1951-02-03 女 の陽占**。docs/60 は「南 禄存・西 司禄」だが、§5 の配置規則（南＝月干、西＝日支の蔵干）では 月干 己→司禄、日支 戌 本元 戊→禄存 となり南西が逆になる。他の5件は規則どおりに一致するので、規則の値をテストの期待値にした。アプリ出力で再確認したい。
3. **1974-01-15 の年運 2027 丁未**。docs/60 は「日に冲、月年に天剋地冲＋庫気刑」だが、規則では 日支 辰 と 未 に冲はなく、月干 乙 と 丁 は七殺でない。規則の結果（月：冲＋庫気刑、年：天剋地冲＋庫気刑）をテストの期待値にした。
4. **1962-03-10 の宿命天中殺**。docs/60 は「寅卯（生年天中殺）」だが、月支 卯 も寅卯に入るため規則では生年＋生月＝二天中殺になる。
5. **大三合会局**。教材に定義が見当たらないため、三合会局が成立しかつ三つの天干が同じ場合として扱った。
6. **起運年齢が 0 になる場合**（節入日当日生まれの逆行など、日数÷3 の四捨五入が 0）。起運年齢は 1〜10 なので 1 歳とした。

## 刑の扱い

冲と刑は重なって成立する（丑未＝冲＋庫気刑、寅申＝冲＋生貴刑）。自刑（辰午酉亥の同支）は比和・律音と重ねて出す。出力では刑を 無礼刑（子卯）・生貴刑（寅巳申）・庫気刑（丑未戌）・自刑 の名で返す。

## 性別が無いとき

大運は順逆が性別で決まるので、性別未入力のときは `taiun` に `male` / `female` の両方を入れて返す。無料診断（生年月日のみ）では大運を使わない想定。
