## 構成で変わったところ

- **第八章「用語の言い換え表」が付いた**（37語）。本文中の初出の括弧（日干支・律音・自刑・大運・陽転）と対応している。docs/50 には無い。
- **第一章は風景の本文をそのまま差し込み**、その続きを風景の言葉（「見えるところを流れない」「乾いた地面」「源へ」）で書いている。docs/50 の「知性で本心を覆う」は使わず、「覆っているのは冷たく澄んだ判断」に寄せた。
- **第五章の見出しが「帝王として、源として生きるということ」**。docs/50・生成サンプルは「帝王として陽転するということ」。チェッカーは番号だけを見るので通る。固定したいなら docs/00 の構成に見出し名を書く。
- 第二章の表は docs/50 と同じ七行。「宇宙盤 直線（60・60・50）」「八門 騰蛇型・順型（北中南272／東中西207）」と数値を入れた。
- 第四章は大運を 35〜44 → 25〜34 → 15〜24 → 45〜54（いま）→ 55〜64（これから）の順で、遡ってから今と次へ。docs/50 は 35〜44 → 前の20年 → これから。
- 処方箋は 2・2・2 の六項目、各項目に「理由：」を付けて宿命表の根拠を書いている。docs/50 は根拠を本文に溶かしている。

## 文体で変わったところ

- 「〜ではなく」がゼロ。docs/50 の反転構文は、言い切りか「〜とは逆の向きで」「〜というより」に置き換わった。「つまり」もゼロ。「だからこそ」は結びに一回。
- 書き手の観察を一度入れた（第三章「この一文を読んだとき、すこし驚きました」）。生成サンプルと同じ場所・同じ型。手本として渡した効果が見える。
- ひらがなを開いている（すこし・ふつう・だれ・ひと・むずかしい）。
- 段落末の格言調は少ない。一行段落は「流れた先を、だれも見ていません。」「大きな転換点です。」「名前をつけます。」のような短い予告に使っている。
- 「苦労は段取りだった／これからは自分が決める」の対は、第五章の結び（docs/50 と同じ章）と羅針盤の表。
- 本文に無い経歴を書いていない。docs/50 にあった「一人親方になり、部門長になり、起業に至った」「人に教えている呼吸と大地」は申込回答に無い情報なので、実機は使っていない。

## 内容で変わったところ

- **五行の働きの対応が docs/50 と違う（実機が正しい）。** 実機は「伝える力＝木56、引き寄せる力＝火0、学ぶ力＝金20」。docs/50 と生成サンプルは「伝える力（火）がゼロ、引き寄せる力（土）と学ぶ力（金）がわずか」。docs/40 の八門法「南＝日干が生じる（伝達）、東＝日干が剋す（財・引力）、北＝日干を生じる（習得）」を癸（水）に当てると、伝達＝木、引力＝火、習得＝金、役割＝土。陽占に禄存星・司禄星（引力）が無いこととも実機の読みが合う。docs/50 は手本なので、この二箇所（第二章の空白の段落、第三章「出口がない」）は訂正が要る（docs/62 の確認待ち）。
- その訂正にともない、**第三章の読みが変わった。** docs/50 は「火ゼロ＝伝える出口がない＝抱える」。実機は「引き寄せる口がゼロだから、入ってきたものが全部自分の器に溜まる＝抱える」。伝える力は木56として「中に眠っている」と書き、2035年の鳳閣星（伝える星）で表に出る、と第四章・第五章につないだ。
- **怖れの正体の名前が変わった。** docs/50 は「源であろうとする自分と隠そうとする自分の隙間」。実機は「湧いても、だれも汲みに来ないのではないか」（引力ゼロの器の怖れ）。羅針盤の表にも入っている。
- **落ちたもの**：「分け御霊」の呼び名。「十人に一人しか陽転しない」。「人の高みに登った者は孤独の罰を受ける」（「同じ地平を見ているひとが少ない星」に言い換え）。「水は平均の約4倍」（「全体の七割」に。196/283）。「あなたの発信が、思想の源泉として機能しようとしている」。
- **足したもの**：排気口 11.3（平均 7〜8）とその読み。年運 2026・2027 の司禄・禄存を「十年の火を迎える前の下見」と読んだ。2027〜2029 を大運の切り替わりの重なり（docs/40 の 1.5年）として書いた。害の部位（2026 心・小腸、2028 肺・大腸・鼻）を年運表に明記。
- **使わなかった算出値**：大運 5歳 壬戌の年柱との庫気刑、2025年 乙巳の日月との冲（去年）。docs/50 も触れていない。2030 年の庫気刑は「刑」とだけ書いた。

## 実機で見るべき点だった項目の結果

1. 風景の差し込み印 → 置いた。
2. 風景の本文の要約再掲 → 無い。風景の言葉を引いて続きを書いている。
3. 「ではなく」の回数 → 0。
4. 位相・星の読み違い → 無い（上の整合）。宿命表に無い位相も書いていない。
5. 文字数 → 8,863。上限 9,000 に近い。effort や指示で短くする余地はあるが、範囲内。
