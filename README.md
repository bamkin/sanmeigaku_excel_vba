# 算命学 宿命鑑定ツール（Excel VBA版）

このツールは、算命学に基づく宿命鑑定を行うExcel VBAツールです。  
生年月日、生時、性別を入力することで、干支、蔵干、通変星、十二大従星、宿命中殺、分析コメントを自動で出力します。

## 使い方

1. Excelファイルを開きます。
2. セル `A1` に生年月日（例: `1990/07/15`）を入力します。
3. セル `B1` に生時（例: `13`）を入力します。
4. セル `C1` に性別（`男` または `女`）を入力します。
5. Excelの「開発」タブからマクロを実行し、`RunSuanmingAnalysis` を選択します。
6. 結果がセル `D1` 以降に表示されます。

## 注意事項

- Excelのマクロを有効にする必要があります。
- 入力形式に注意してください。
